# Monku Fusionプロンプト改訂の設計記録（2026-09-26）

前版: monku-fusion-engine-2026-09-21.md

## 改訂の動機と課題

1. **`entropyCore` の語尾テンプレ化（Bot化）の解消**:
   - 2026-09-21版の「〜という願いがあるのかもしれない」という例示記述にLLMが過剰適合し、毎回答の語尾が画一的になっていた問題を解消。
   - 「ユーザーの入力内容を基にした仮説であることが伝わる表現にする」と改め、文脈に応じた自然で切実な語尾・表現の多様性を解放。

2. **思考ステップと返信（pacifyReply）の因果の明確化**:
   - ステップ1〜3（不満の燃料化、皮肉の素の不満化、人格から場への視点移動）で entropyCore の土台を確立した上で、ステップ4で pacifyReply を作成する思考のバトンリレーを明記。
   - pacifyReply の定義を「entropyCore で捉えた願いを踏まえ、そのまま相手へ送れる自然な一文」へと整理。

3. **冗長な二重記述（実行順序）の削除**:
   - 「思考・適応のレイヤー」とほぼ重複していた「## 実行順序」を削除し、プロンプトのノイズを低減。

4. **制作動機・哲学の完全保持**:
   - 「文句のエネルギーを正方向に転換する」「強ければ強いほど高く飛ぶ」「イノベーションの一次資料」という根幹の哲学は一文字も薄めずに保持。

## 反映と検証

- `scripts/sync-prompt.mjs` の参照元を `monku-fusion-engine-2026-09-26.md` に更新し、`npm run prompt:sync` で `shared/fusion-prompt.ts` に正常反映。
- `tests/prompt.test.ts` を含む全テストスイート（10ファイル・71テスト）がすべてパスすることを確認済み。
