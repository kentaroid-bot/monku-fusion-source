旧コード・旧接続は残数共有と直近5件の公開一覧を維持し、アカウントの権限を自動追加しません。アカウント連携トークンでは退会、別端末の接続管理、新しい接続コード発行はできません。コードの権限・期限・解除はサーバーで検証します。

接続情報とAPIキーはchrome.storage.localに保存し、拡張の信頼された画面だけにアクセスを限定します。APIキーはGoogleだけ、接続情報は専用Convexだけへ送信します。選択文章はchrome.storage.sessionから読み出し後に削除。入力と結果の比較履歴はパネルのメモリだけです。生成処理用の非公開結果キャッシュなど既存のサーバー保存方針はWebの説明と共通です。

権限の追加はありません（contextMenus / sidePanel / storage、Google Geminiと専用Convex）。ストアのデータ分類では「認証情報」にアカウント連携トークン、「保存内容」に表示設定、「Convex用途」にアカウント連携といいね/投稿管理を含めて説明します。全サイトの読取・閲覧履歴・リモート実行コードは使いません。

- ホスト理由：generativelanguage.googleapis.com は本人のGemini APIキーによる生成、hip-hound-497.convex.site は専用の接続認証・残数共有・安全確認・生成・決済確認・明示公開と取り下げ・全件といいねと本人投稿・期限付きアカウント連携と解除に使用します。他のサイトへの包括的なアクセス権限は要求しません。
